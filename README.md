# 全屏助手

选择已打开的游戏窗口，点击全屏；需要时，一键恢复原来的位置、大小和边框。

**[下载便携版 ZIP](https://github.com/ChuanGuz/FullscreenAssistant/releases/latest/download/FullscreenAssistant-v1.2-portable.zip)** · **[直接下载 EXE](https://github.com/ChuanGuz/FullscreenAssistant/releases/latest/download/FullscreenAssistant.exe)** · [版本与更新](https://github.com/ChuanGuz/FullscreenAssistant/releases/latest)

当前版本 **1.2**，支持 **Windows 10 / 11 64 位**，需要 .NET Framework 4.x（现代 Windows 通常已自带）。无需安装。

仓库目前为私有，查看和下载需要登录有访问权限的 GitHub 账号。

## 怎么使用

1. 打开游戏，先切换到窗口模式，等待加载到标题画面。
2. 解压便携版，双击“全屏助手.exe”；单独下载的“FullscreenAssistant.exe”也可以直接运行。
3. 从列表里选中游戏窗口，保持默认的“智能全屏”，点击蓝色“全屏”按钮。
4. 需要恢复时，按 Alt+Tab 切回助手，选中窗口，点击“恢复窗口”。

列表每 5 秒刷新，也可以手动刷新，或搜索窗口标题、进程名称。支持选择目标显示器，同一程序的多个窗口会分别列出。

“恢复全部”会恢复所有受控窗口；正常关闭助手时，也会尝试自动恢复。

## 选择哪种全屏方式

| 模式 | 用途 |
| --- | --- |
| 智能全屏（推荐） | 识别支持的 RPG Maker 游戏，优先调用原生全屏；其他窗口采用标准方式。 |
| 标准窗口全屏 | 去除系统标题栏和边框，将内容区域铺满显示器。 |
| 兼容裁边 | 标准方式仍有残留缩放边框时使用，可能裁去少量边缘内容。 |
| 游戏原生全屏 | 明确使用已支持游戏的原生方式，无法识别时会提示。 |

“顶部额外裁切”先保持为 **0**。仅在兼容模式仍有多余的自绘标题栏时逐步增加，避免裁掉菜单或画面。

### RPG Maker 原生适配

支持识别标准的 RPG Maker MV / MZ + NW.js：游戏 EXE 旁有 nw.dll，游戏目录或 www 中有对应核心脚本，且保留标准 F4 全屏处理。

识别成功会显示引擎名称。助手确认游戏已激活、组合键松开后，调用游戏自身的 F4 全屏功能。切换时请松开 Ctrl、Alt、Shift、Windows 和 F4 键。

重复点击全屏不会把游戏切回窗口；尊重游戏中手动按 F4 退出全屏的操作。如果操作前已经是原生全屏，恢复时会保留原状态。

## 恢复与快捷键

- Alt+Tab 切回助手，使用“恢复窗口”或“恢复全部”。
- 双击系统托盘的助手图标，或右键选择“恢复全部窗口”。
- 默认恢复快捷键 Ctrl+Alt+F11；若无法注册，会依次尝试 F10、F9。**以界面右下角显示的组合为准**，快捷键不可用时仍可使用按钮和托盘。

助手保留第一次操作前的位置、大小、边框、置顶和最大化／最小化状态，重复全屏不会覆盖最初记录。

管理窗口时会暂时生成“窗口恢复记录.xml”。异常退出后，请从同一文件夹重新启动助手，尝试恢复原窗口。管理期间请保留该文件，恢复后会自动删除。

使用工具后再点应用自己的最大化按钮时，助手会撤销工具裁边，交给应用自己的布局；仍可通过助手恢复最初状态。

## 兼容范围和常见问题

- 并非所有游戏均兼容。固定渲染尺寸的游戏可能只扩大外部窗口，内部画面缩放仍需游戏本身支持。
- 其他引擎、禁用 F4 的插件或资源与启动器分离的安装方式，可能需要标准全屏或兼容裁边。独占全屏游戏应先切换为窗口模式。
- 标准模式移除系统标题栏，也可能隐藏资源管理器等应用右上角的系统按钮，可通过助手恢复。
- 本版本没有通用的鼠标自动隐藏功能，鼠标隐藏由游戏本身控制。
- 游戏以管理员权限运行时，助手也可能需要相同权限。
- 出现黑屏、裁切或画面异常时，先用“恢复全部”、恢复快捷键或托盘恢复。

助手通过 Windows 窗口功能和已识别游戏的原有快捷键工作，不修改游戏文件，不向游戏注入 DLL。

## 源码与构建

```text
全屏助手.exe
使用说明.txt
README.md
开发资料/
├─ 源码/              C# 源码、现有图标及程序清单
├─ 验证/              测试源码、执行脚本与验证说明
├─ 重新构建.cmd
└─ 更新说明.txt
```

双击“开发资料/重新构建.cmd”，使用系统自带的 C# 编译器，在上一级生成“全屏助手.exe”，无需安装 .NET SDK。构建前先正常退出助手。

此前已完成 14 项基础窗口测试、3 项自绘边框回归，以及检测、全屏、恢复、退出恢复的界面流程验证。曾使用《樱御前》（MZ / NW.js）验证 2560×1440 原生全屏与准确恢复。这些验证不代表所有游戏均已测试；MV 标准适配已实现，真实游戏验证使用 MZ。

常规测试只操作独立测试窗口，不会自动打开真实游戏：

```powershell
powershell -ExecutionPolicy Bypass -File .\开发资料\验证\run-tests.ps1
```

真实游戏适配测试见“开发资料/验证/RpgNativeTests.cs”，需要显式提供游戏 EXE 路径后单独运行。仓库保留测试源码，旧测试输出和截图已在整理时移除。
